Pemasangan kali pertama

  1. Buka Google Sheet asal menggunakan akaun yang mempunyai akses mengedit.
  2. Pilih Extensions → Apps Script.
  3. Gantikan kandungan Code.gs dengan kod di bawah.
  4. Tekan + → HTML, namakan Index, kemudian tampal kod Index.html.
  5. Simpan. Pilih fungsi setup dan tekan Run. Semak permintaan akses Google dan benarkan jika sesuai. Jika akaun sekolah menyekat Apps Script, hubungi pentadbir Google Workspace sekolah.
  6. Selepas berjaya, muat semula Google Sheet. Menu TEMIN Aset → Buka sistem membolehkan sistem digunakan terus di komputer.
  7. Untuk telefon / tablet: Deploy → New deployment → Web app. Pilih Execute as: Me dan akses Only myself untuk kegunaan sendiri. Tekan Deploy, kemudian buka URL web app yang Google berikan.
  8. Simpan pautan web app sebagai pintasan pada telefon. Jika mengemas kini kod kemudian, gunakan Manage deployments → Edit → New version → Deploy supaya pautan sedia ada kekal.

Cara penggunaan & catatan

Sheet sasaran: PERALATAN DALAM KELAS. ID telah ditetapkan dalam Code.gs.

  • Data asal 5 DELTA kekal. Kipas, kerusi dan meja menggunakan kolum A:J yang sedia ada.
  • Pendingin hawa menggunakan kolum K:M; lampu menggunakan N:P. Jangan letakkan data lain dalam K:P sebelum pemasangan.
  • Tab ASET_LOKASI, ASET_EKON dan ASET_LOG diwujudkan oleh setup.
  • Lokasi asal diambil daripada Sheet1. Bilik Guru, Bilik Akses dan Bilik j-QAF disediakan sebagai pilihan awal; bilangan bermula pada sifar.
  • Bilangan dalam borang ialah jumlah semasa, bukan tambahan. Contoh lampu dua tiub: satu elok dan satu rosak = 1 elok + 1 rosak.
  • Setiap pendingin hawa didaftar sekali sahaja; gunakan Sunting untuk menukar status. ID sistem dijana automatik. No. daftar aset rasmi ditaip secara manual dan boleh dilengkapkan kemudian.
  • Nombor daftar aset yang sama tidak boleh digunakan oleh dua unit. Jenama, model, HP dan catatan disediakan.
  • Dashboard membaca rekod apabila dibuka, selepas simpan, atau apabila Muat semula ditekan. Perubahan terus oleh pengguna lain dalam Sheet memerlukan Muat semula.
  • Gunakan borang untuk urus lokasi. Nama lokasi menjadi kunci padanan; jangan tukar nama lokasi terus dalam Sheet tanpa menyelaraskan rekod berkaitan.
  • Sistem mengesan perubahan serentak bagi suntingan borang, mengunci proses simpan dan merekod sejarah tindakan. Elakkan suntingan terus pada Sheet ketika borang sedang menyimpan.
  • Gambar lampu digunakan sebagai contoh cara mengira sahaja. Tiada lokasi atau rekod kerosakan lampu telah dimasukkan berdasarkan gambar itu.
  • Pakej ini belum dipasang atau diterbitkan pada akaun Google. Google Sheet asal belum diubah dalam sesi ini. Ujian logik dijalankan dalam persekitaran simulasi; sambungan dan paparan dalam Apps Script perlu disemak selepas pemasangan.

Pratonton susun atur

Pratonton ini menggunakan data asal 5 DELTA yang dibaca daripada Sheet. Ia tidak menyimpan perubahan. Pasang Apps Script untuk penggunaan sebenar.
