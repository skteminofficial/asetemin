TEMIN Aset v3

Jumlah dahulu. Isi Elok atau Rosak. Baki dikira automatik.

Pasang / kemas kini

Sheet sedia ada telah dirombak kepada v3. Semua 45 lokasi bermula dengan semakan kosong. Borang web menggunakan kod baharu ini.

  1. Buka Google Sheet TEMIN Aset → Extensions → Apps Script.
  2. Gantikan seluruh kandungan Code.gs dengan kod v3 di bawah.
  3. Gantikan seluruh kandungan fail HTML Index dengan Index.html v3 di bawah. Jika belum ada, pilih + → HTML dan namakan Index.
  4. Tekan Save. Pilih fungsi setup → Run. Semak permintaan kebenaran Google jika dipaparkan. setup tidak mengosongkan semula rekod v3 yang sudah diisi.
  5. Sudah pernah deploy? Pilih Deploy → Manage deployments → Edit (pensel) → New version → Deploy. Pautan web app lama kekal, tetapi memaparkan sistem baharu selepas dimuat semula.
  6. Belum pernah deploy? Pilih Deploy → New deployment → Web app. Execute as: Me. Who has access: Only myself. Tekan Deploy dan buka URL yang Google berikan.
  7. Muat semula pautan web app. Pastikan tajuk TEMIN Aset v3 dan borang memaparkan Jumlah keseluruhan, Elok, Rosak.

Jika akaun sekolah menyekat penggunaan Apps Script, minta pentadbir Google Workspace menyemak akses.

Cara penggunaan

  1. Pilih lokasi. Semua nama kelas dan 21 bilik khas telah disediakan.
  2. Untuk lampu, kipas, kerusi dan meja, pilih Belum disemak, Tiada atau Ada.
  3. Jika Ada, masukkan jumlah. Contoh: 30 kerusi. Isi Rosak 10 → Elok automatik 20. Jika ubah Elok kepada 25 → Rosak automatik 5.
  4. Bilangan mesti nombor bulat, tidak negatif dan tidak melebihi jumlah. Jika tersalah terlebih, borang meminta pembetulan sebelum boleh disimpan.
  5. Lampu berkembar dikira 1 point. Jika satu tiub tidak menyala, rekod 1 point rosak dan tulis “1 daripada 2 tiub tidak menyala”.
  6. Penyaman udara: pilih Ada lalu gunakan pendaftaran satu unit. Isi jenama dan lokasi, no. pendaftaran aset manual (boleh dilengkapkan kemudian), status Elok/Rosak, model, HP dan catatan.
  7. Simpan semakan. Setiap simpan menggantikan bilangan semasa bagi lokasi tersebut.
  8. Gunakan + Tambah lokasi untuk lokasi baharu. Lokasi tambahan turut mendapat borang kosong.

Lokasi lengkap bermaksud 4 jenis peralatan telah disemak dan semakan ekon lengkap. Pilihan Ada bagi ekon memerlukan sekurang-kurangnya satu unit didaftarkan.

Tab aktif: DASHBOARD, REKOD_V3, LOKASI_V3, EKON_V3, LOG_V3, PANDUAN. Data lama disimpan dalam tab arkib tersembunyi dan tidak digunakan dalam dashboard.

Dashboard dibaca semasa sistem dibuka, selepas simpan, atau apabila Muat semula ditekan. Gunakan Muat semula untuk perubahan oleh pengguna lain.

Pratonton borang v3

Pratonton sahaja. Pilih lokasi, pilih Ada, masukkan jumlah dan cuba ubah Elok / Rosak. Pratonton ini tidak menyimpan ke Google Sheet.
